# JUnit 5 Homework – Software Testing and Quality Assurance

This project contains unit tests for the following Java classes using JUnit 5:
- `Calculator`
- `Product`
- `UserService`
- `RecipeBook`

---

## 🔀 Branches

- `release-1 [CURRENT BRANCH]` → Designed for **IntelliJ IDEA** (manual JAR management)
- `release-2-eclipse` → Structured for **Eclipse** IDE with working `.classpath` and `.project` files

---

## 💡 IntelliJ IDEA Setup (release-1)

> No Maven or Gradle used. Dependencies are added manually.

### 🧩 Required JARs (Add to Project Manually)

Download and add these to your project via:
> File > Project Structure > Modules > Dependencies > + JARs or Directories

- `junit-jupiter-api-5.10.0.jar`
- `junit-jupiter-engine-5.10.0.jar`
- `junit-platform-suite-api-1.10.0.jar`
- `apiguardian-api-1.1.2.jar`
- `opentest4j-1.3.0.jar`

You can get them from [Maven Central](https://search.maven.org/).
