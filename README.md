## 🧪 Eclipse Setup (release-2-eclipse)

This branch is already configured for Eclipse usage:
- Just clone this branch and open it with Eclipse IDE.

### ✅ Steps:
1. Open Eclipse
2. Import as **Existing Java Project**
3. Right-click the test suite or any test class → Run As → JUnit Test
